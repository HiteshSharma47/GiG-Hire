# Gig Platform

A MERN Stack Gig Platform that connects clients with freelancers, allowing users to offer and hire services online. The platform provides features for creating gigs, browsing available services, managing orders, and communicating between clients and freelancers.

Users can create profiles, publish gigs with pricing and descriptions, search for services, place orders, and leave ratings and reviews after completing a project.

The project is built using MongoDB, Express.js, React.js, and Node.js, with authentication and role-based functionality for different types of users.
